How to work on your file
Click your file in this folder and download it.
Open it in PowerPoint. Put your screenshots in the gray boxes and edit the text so it matches what you actually built.
Save it, then come back to this folder and use Add file > Upload files. Drag in your edited file and commit. Keep the same file name so it replaces the old version.
Rules

Do not rename the files.
Keep videos out of this folder. GitHub only takes files up to 25 MB, so share the clips on Discord or email to me (kkishine@asu.edu)
Hide tokens, password hashes, and anything from the .env file in your screenshots.
